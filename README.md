# LMSKaynakYonetimiHizliTasarimSprinti
Bu proje, BÖTE405 Proje Geliştirme dersi kapsamında, bir üniversitenin Öğrenme Yönetim Sistemi'ndeki (LMS) "Kaynaklar/Dosyalar" bölümünde yaşanan erişilebilirlik ve karmaşa sorunlarını çözmek amacıyla gerçekleştirilmiş 120 Dakikalık Bireysel Tasarım Sprinti çalışmasıdır.
